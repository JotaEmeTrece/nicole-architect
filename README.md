# 🏛️ Nicole Architect

Suite de herramientas profesionales para arquitectos, diseñada como Progressive Web App (PWA). Centraliza la gestión de proyectos, levantamientos, planos, moodboards y herramientas de cálculo en una sola plataforma.

> ⚠️ Este proyecto es un prototipo funcional (demo). Las secciones están diseñadas e implementadas visualmente; la lógica de negocio completa está pendiente de desarrollo.

## ✨ Módulos

### Field
- **Levantamientos** — Gestión de levantamientos arquitectónicos con mediciones y croquis
- **Planos** — Subida y anotación de planos por proyecto
- **Checklists** — Listas de verificación para inspecciones de obra

### Studio
- **Moodboards** — Tableros de inspiración y referencias visuales por proyecto
- **Calculadoras** — Herramientas de cálculo para área, materiales y más

### Design
- **SunPath** — Análisis de trayectoria solar para diseño bioclimático

## 📋 Dashboard
- Vista general de herramientas disponibles por módulo
- Proyectos recientes con estado (activo / completado)
- Navegación lateral categorizada por área de trabajo

## 🚀 Correr localmente

```bash
git clone https://github.com/JotaEmeTrece/nicole-architect.git
cd nicole-architect
pnpm install
pnpm dev
```
